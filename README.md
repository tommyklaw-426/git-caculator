## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear the display

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open the index.html file in a web browser.


## Advanced Features Added
- **Scientific Operations:** Percentage (%), Sign Toggle (+/-), Square Root (√), and Exponentiation (^).
- **Error Handling:** Division-by-zero protection ("Cannot divide by 0") with automatic error clearance on subsequent input.
- **Interactive Calculation History:** Side panel tracking previous calculations with click-to-load functionality to reuse past results.
- **Memory Registers:** Full MC, MR, M+, and M- functionality.
